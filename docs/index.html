Overview

Tilt CSV/TSV spec tables for quick inspection and cleanup. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/tiltspec.git
cd tiltspec
node src/cli.js --help
node --test
