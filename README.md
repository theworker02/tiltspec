# tiltspec

Tilt CSV/TSV spec tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tiltspec/

## Install / run

```bash
git clone https://github.com/theworker02/tiltspec.git
cd tiltspec
node src/cli.js
node --test
```
